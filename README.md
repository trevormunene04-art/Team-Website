## Reflection

1. We learned how HTML provides the structure of a website and how different elements work together to create complete webpages.

2. We learned how CSS improves the appearance of a website through colours, layouts, spacing and responsive design.

3. JavaScript helped us understand how to make websites interactive through features such as project filtering, navigation and form validation.

4. Working as a team helped us share responsibilities, exchange ideas and learn from each other's strengths.

5. One challenge we encountered was managing our GitHub repository, especially cloning the project, tracking changes, creating commits and pushing our work.

6. This project improved our confidence in web development and taught us the importance of collaboration, problem-solving and continuous learning.
